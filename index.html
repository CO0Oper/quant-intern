The pipeline

From a YouTube URL to a backtested verdict

An agent drives the whole chain. The front half is code + LLM reasoning; the back half is real chart control through the TradingView MCP — no hand-rolled automation.

Why it's different

Built to tell the truth, not to flatter

⚖️

Always vs buy & hold

A backtest in isolation looks like cherry-picking. Every result is shown against its same-window benchmark, so the verdict is objective.

🔑

No API key

In CLI-agent mode the agent is the LLM and drives the TradingView MCP tools directly. Nothing to provision.

🛟

Self-healing compile

A compile-and-fix loop repairs generated PineScript, with a tested known-good fallback so a run never dead-ends.

📊

Ticker × timeframe matrix

One strategy, swept across instruments and resolutions, so a single lucky window can't masquerade as edge.

📡

Watchable dashboard

A zero-dependency web view streams every step live — rules, code, compile status, results, verdict.

🗂️

Every run recorded

Append-only results log is the source of truth; each strategy is saved under a canonical, collision-free name.
